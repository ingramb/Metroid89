Metroid 89

**** WARNING ****
Unfinished product.  Highly unstable.  Provided as is, with no support.  Use on a real calculator at your own risk.  

About
--------------------------------------------------------------------------------
This is a project I started a long time ago.  For many years, I told myself that this would be the year it would be finished, but alas it never happened.  At this point, it has been probably 10 years since I've done any serious work on the project.  This isn't something that I will work on again, but it's been sitting on my hard disk(s) for a long time, and it seems like a waste not to release what I have, so here it is.  Hopefully it will be fun to play around with at least.

Installing
--------------------------------------------------------------------------------
Transfer all files to your calculator.  They all need to be archived.  You will need to transfer/archive in several steps as the files are too large to fit all at once in RAM.  You will need KerNo/HW3Patch/whatever is needed to launch large ASM programs on your calculator.

How to play
--------------------------------------------------------------------------------
[Arrows] - Move
[2nd] - Shoot
[Diamond] - Jump
[F1] - Select main beam weapon
[F2-F4] - Select special weapons
[Apps] - Enter map screen, [2nd] here goes to status screen, [Diamond] here exits
[Esc] - Quit
[Shift] - CHEAT!!!

This is more or less a clone of Super Metroid, and most of the items and abilities from that game appear.  Pressing shift will unlock them all.  Many (but not all) can be found in the world.


Developers
--------------------------------------------------------------------------------
All of the source code I could find is provided in this package.  Anyone brave enough to look at it is welcome to do whatever they want with it.  As previously mentioned, I haven't worked on this in 10 years.  I don't know if it even still compiles.  The /Src folder contains all the code for the game itself.  The /Tools folder contains the source code for three windows tools.  MapEditor is used to create levels.  SpriteMaker is used to layout sprites, and convert to grayscale images.  RidleyEditor is used to create Ridley's tail animation (yes he has his own tool).  All of these are windows programs build with Allegro v4.  The /Data folder contains all of the source assets I could find.  None of this will compile/work out of the box.  If you try to make it work, you will likely have to deal with out of date libraries, hard coded paths, and lots of other nastiness.  I think there's a few "bonus" files thrown in that belong to other unfinished projects in there.  You have been warned :-)

I am willing to provide minimal support regarding the code.  Like if there's a missing file, I will see if it's still on my disk somewhere :-)  But I don't have time to give any serious help.  Contact me at ingramb AT gmail DOT com.
